# Real-Time Student Engagement Detection Using Facial Analysis (MediaPipe and OpenCV)

This project focuses on real-time student engagement detection using facial analysis. It involves preprocessing video data, applying MediaPipe for face detection, and training deep learning models (VGGNet and EfficientNet B3) on the DAiSEE dataset. A web application was built with Flask (backend) and React (frontend) to enable live testing, and it has been successfully deployed on Render: https://student-engagement-detection.onrender.com/. Full code and instructions are available in this repository.
